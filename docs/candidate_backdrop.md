# Windows 11 候选窗毛玻璃试验

**当前状态：暂时屏蔽。** 2026-10-15 用户继续实测发现文字显示仍有异常，先前像素夹具通过不能代表实际显示问题已经解决。按维护者要求，candidate_backdrop.cpp 的 kCandidateBackdropEnabled 固定为 false，统一入口不再创建或启用毛玻璃窗口；实现代码保留，原有背景透明度继续使用。后续处理文字显示并重新验收后才可显式恢复。下文为保留的实现和历史验证记录，不代表当前启用或问题已彻底修复。

## 使用范围

只接入独立 renderer 的候选词弹窗，不改变设置主窗口、悬浮工具栏、对话框或设置页的离屏预览。Windows 11 工作站（build >= 22000）中，当现有“背景透明度”小于 100% 时自动尝试启用。100% 保留原有不透明主题；不修改默认透明度或用户配置。深浅色、主题、文字、选中项继续由原渲染器负责。

其他 Windows 版本、系统关闭透明效果、高对比模式、DWM 关闭或接口调用失败时，隐藏辅助背景并使用原来的透明绘制。系统效果还可能受到系统策略、驱动、远程桌面等运行环境影响。

## 实现与边界

原候选窗口保留 WS_EX_LAYERED / UpdateLayeredWindow 的逐像素绘制。CandidateBackdrop 管理一个位于文字窗口下方、仅覆盖候选面板的辅助窗口；不获取焦点、禁用输入、不创建任务栏入口。辅助层不与文字窗口建立 owner 关系，停用模糊不会连带隐藏候选文字。窗口位置、大小和显示状态跟随实际候选宿主，隐藏/销毁候选时隐藏辅助层，renderer 退出时销毁；主题或系统合成设置变化时重建。背景移动/大小与层级不变时不重复设置窗口位置，模糊策略只在创建时应用。

初次尝试 DwmSetWindowAttribute 的 Desktop Acrylic 时，Windows 11 build 26200 上的非激活弹窗实际显示为实色；接口返回成功不代表产生模糊，因此该路径没有交付。试验版改为动态解析 User32 的 SetWindowCompositionAttribute，使用 WCA_ACCENT_POLICY / ACCENT_ENABLE_BLURBEHIND，以保留不激活窗口的实时模糊。现有半透明主题层继续提供颜色和透明强度，文字层保持清晰；生产实现不读取屏幕像素或保存桌面截图。

此为试验路径：微软[不推荐使用 SetWindowCompositionAttribute](https://learn.microsoft.com/en-us/windows/win32/dwm/setwindowcompositionattribute)，其 accent-policy 结构/枚举不是稳定公开契约。使用本机已有 User32 导出、不加载外部 DLL；接口缺失或拒绝调用时回退原效果。后续 Windows 构建应重新验证，不能将当前结果宣称为所有 Windows 11 环境兼容认证。

## 验证

candidate_backdrop_test 的默认模式在屏幕之外创建自有测试窗口，检查禁用门控、真实窗口位置及 Z 序、不抢焦点、展开布局、移动、隐藏与资源释放；无效果可用时检查没有可见残留层。可选 `--visual <输出目录>` 会短暂显示自制彩色条纹背景和候选窗，只捕获这个测试区域并保存前后对照，不使用用户的真实输入或桌面内容。实际模糊不以接口返回值单独判定：截图检查高频条纹对比度下降，且不同背景色仍能透出，排除实色回退。

2026-10-15 在 Windows 11 build 26200 实测：45% 背景强度下，条纹相邻像素平均差异从 11.6914 降至 0.327739，左右背景颜色差异为 17；候选文字保持清晰，启用效果不改变前台焦点，停用后文字窗口仍可见。未安装替换当前输入法，没有修改现用透明度设置。

## 文字边缘与收起同步修复

2026-10-15 用户反馈后增加了两个先失败的回归夹具：透明候选“啤酒”的 14px 笔画像素总量为系统原生黑字白底灰度抗锯齿的 1.13128 倍；缺少 WINDOWPOS 通知时，候选收起后的面板为 530×40，而辅助模糊层仍是 530×168。

透明文字改用黑字白底的原生灰度蒙版并反相获取覆盖率，避免白字黑底蒙版引入的笔画增重；每次文字绘制和蒙版清理使用同一裁剪范围，防止邻近文字复用残留覆盖率。文字颜色与背景透明度继续分开合成，不调整字体粗细设置，不修改不透明模式的 ClearType 路径。新增 14/16/20/24px“啤酒”夹具，除像素总量外还逐点比较笔画边缘，允许至多 1 级量化差异。

候选宿主每次提交布局后直接同步模糊层，不依赖 UpdateLayeredWindow/SetWindowPos 是否发送 WINDOWPOS 通知；隐藏分支也显式隐藏模糊层。回归使用不转发位置通知的真实分层宿主，先展开再收起并检查模糊层缩至面板范围，同时检查隐藏后的清理。
