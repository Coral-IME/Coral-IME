# 字符神经模型实验接口

输入整串精确命中真实中文词库词条时，直接按词库自身权重生成候选，跳过统计语言模型的启发值计算、组句路径搜索和 GPT2 评分。主词典和用户自造词均适用，未分配主词典 ID 的用户词通过命中来源标记与默认音节回退区分。完整词条之间沿用词库权重顺序；前缀词条照常保留。模糊/编辑纠错、英文回退和扩展生成结果不算这种精确命中。

未精确命中完整词条的输入才搜索最多 32 条普通中文组句路径，再对基础排序的前 8 条路径按字数门槛使用字符模型重排。通过 `CORAL_CHARACTER_RERANK_PATHS=1..32` 可构建对照版本（1 路等价于没有可重排对手）；默认是 8，12 是较保守的对照选项。短名单内不符合字数门槛的项不参与评分，也不从尾部补位。尾部路径保留基础分数。只命中前缀词仍需要组句。切分、区间取词、每状态最多 8 条路径和 32 路搜索预算不变，普通中文仍只展示最佳组句，混输沿用独立路径。

字符模型支持默认编译开启，权重是独立的外置资源。源码不分发权重；运行包生成时可用显式参数选择外部模型，打包与安装保留同一文件及摘要。本地对比可使用已有实验权重，后续替换为独立训练的模型。模型不存在或加载失败时回退原排序。普通词模型和字符模型分别加载，不修改原词库或一二元文件。

## 启用与评分

在“高级 → 智能预测”下方提供“智能候选”开关，默认开启，说明为“使用gpt2进行长候选词优化，该功能可能会造成一定卡顿”，下方提示“修改后重启输入法生效”。设置以 `smartCandidates` 持久化；引擎启动时读取一次，当前运行中的引擎不随配置刷新或会话切换改变。关闭后不加载字符模型，不复制神经上下文，也不执行 GPT2 推理或诊断评分；普通统计组句保留。该开关独立于“智能预测”。重启指停止并重新启动引擎宿主，仅关闭设置窗口或切换输入窗口不会生效。

构建能力默认开启，开发者仍可使用下列参数生成完全不包含引擎神经重排的版本；这种版本中程序内开关不启用被排除的功能。正常用户对比使用程序内开关即可。

```powershell
cmake -S . -B build/neural-on -DCORAL_ENABLE_CHARACTER_MODEL=ON
cmake -S . -B build/neural-off -DCORAL_ENABLE_CHARACTER_MODEL=OFF
cmake --build build/neural-on --config Release -- /m:1 /nr:false
cmake --build build/neural-off --config Release -- /m:1 /nr:false
```

候选字数门槛通过编译参数 `CORAL_CHARACTER_RERANK_THRESHOLD=N` 调节，默认 `3`，合法范围 `0–63`。只有原始最佳完整候选的 Unicode 字符数 **大于 N** 才进入重排，所以默认三字及以下整组跳过，四字起参与；不按 UTF-8 字节数或拼音字母数计数。进入重排后也只给超过 N 字的候选评分与加分，较短候选保留基础分数；满足门槛的候选不足两条时跳过模型。这样短首选不会因为存在长备选而触发推理。较短候选的分数保持不变，但长候选加分后仍可能改变整组排序。

例如：`cmake -S . -B build/neural-on -DCORAL_CHARACTER_RERANK_THRESHOLD=3`。参数在编译时固定，调整后需要重新构建；设为 `0` 允许所有非空长度参与，`CORAL_ENABLE_CHARACTER_MODEL=OFF` 仍会完全排除引擎的神经重排功能。字数判断之前不会进行神经推理；模型资源仅在启动时“智能候选”开启的情况下加载。

开启版自动查找语言模型同目录下的 `character_model.coral`，通常是运行资源中的 `data/generallexicon/character_model.coral`。不会从第三方安装目录提取文件。生成安装包时向 build_runtime.py 传入 --character-model PATH，默认将浮点矩阵转换为逐输出行 INT8 后放入运行包，并分别记录源文件与产物摘要；输入已为 INT8 时直接复制。使用 --character-model-format preserve 可保留原文件精度。package_windows.py 自动收集已记录的模型，可用 --require-character-model 强制要求模型存在。未传模型参数的通用构建仍不包含权重。也可以在启动前指定绝对模型路径和权重：

```powershell
$env:CORAL_CHARACTER_MODEL = 'C:\models\character.coral'
$env:CORAL_CHARACTER_WEIGHT = '0.5'
```

权重范围 0–8，未指定时为 0.5，0 关闭评分。编译关闭时忽略这些环境变量。路径和权重在资源加载时固定，变化后需重新启动引擎。公开演示使用人工小网络。独立训练与导出见 [字符模型训练](character_model_training.md)。

每条候选计算无 EOS 的字符对数概率之和。以前文和内部基础首选为参考，分数修正为：

`bonus = weight * min(16, max(0, neural(candidate) - neural(reference))) / (1 + 拼音字母数)`

加分与基础概率处于同一拼音长度尺度，再按原候选比较规则择优。公式是可评测的初版策略，权重需在单独校准组确定，不代表普适参数。字数不同仍含语言模型长度效应，本接口不调整拼音切分。

同一请求内按字符前缀共享 KV 缓存；不同请求不共享候选缓存。深度优先评分共用一份 KV 与词表输出工作区，回溯时恢复长度，不逐层复制完整历史和词表向量。有效上屏条件通过 `set_character_context` 提供，最多取末尾 32 个 Unicode 标量。前文未知字断开神经历史，候选含未知字则该项不加分；参考首选不可评分时整组不加分。非法 UTF-8、超长文本、资源预算失败同样保留基础排序。

推理使用 C++17 的嵌入、预归一化因果注意力、近似 GELU 和共享嵌入输出投影；无 Python、TensorFlow 或网络依赖。模型以不可变共享所有权交给后台任务，任务不借用解析器、词格或临时 arena；模型重新加载和宿主关闭不会使在途任务悬空。

## 两阶段候选与交互时序

正式会话端口的输入、删除、翻页和选中后的解析不再内联执行神经推理。第一阶段始终先返回词库与统计组句候选，并只收集满足原有字数和词库命中门槛的模型输入快照。没有模型或开关关闭时不安排优化。

TSF 在输入静止 120ms 后才发起优化，之后每 25ms 做一次短轮询。GPT2 在宿主拥有的独立低优先级线程中计算，不持有主引擎锁；宿主最多一个计算中任务和一个最新待执行任务。新任务替换旧任务，过期推理在上下文或候选树节点边界检查取消。整批评分的软预算为 150ms，包含全部捕获的模型调用；超时、取消、异常或评分不完整时保留基础候选，禁止提交部分神经加分。软预算可能超出一个不可中断的节点计算时间，不是硬实时保证。

第二阶段只回放完整评分，不再次执行模型。回放须与模型实例、上下文和完整候选序列精确匹配，否则放弃优化。前端还核对会话、输入版本、独立优化代次和前台窗口；提交、重置、新输入、删除、光标编辑、选词导航、候选展开、隐藏、配置变化或会话替换都会使旧结果失效。候选实际变化时提升显示版本并重新生成候选 ID，旧的渲染器操作不能选中新位置；结果相同则不刷新。

输入速度不作为正确性前提，不丢弃或合并原始按键。快速盲打后立即提交，使用当时已显示的基础候选，不等待模型；新一轮即使输入相同拼音，也有新的版本。长按和删除在基础路径照常处理，不对重复字母作一概过滤。停止超过 120ms 并不保证每次都能得到优化：模型预算、忙时替换和用户继续操作均可能让该次保留基础结果。

`coral_parse_bench` 等直接调用解析器的离线工具仍同步评分，适合测量模型对准确率的影响；其耗时不能代表产品第一阶段延迟。产品验证须覆盖真实宿主、桥接、定时消息、过期结果和提交时序。公开人工网络验证异步评分与原评分一致，控制器测试用每键 1ms 的连续输入和主动延迟结果覆盖时序边界。

## CCHLM001 格式

所有整数和 IEEE 754 float32 显式小端，头长 128 字节，不使用编译器结构体布局。文件上限 256 MiB，拒绝尾部扩展，失败保留此前可用模型。

| 偏移 | 字段 |
|---|---|
| 0 | 8 字节 `CCHLM001` |
| 8、12 | u32 版本 1（FP32）或 2（INT8 矩阵）、头长 128 |
| 16 | u64 文件总字节数 |
| 24、28、32、36 | u32 层数 L、隐藏维度 D、头数 H、前馈宽度 F |
| 40、44 | u32 词表 V、位置数量 P |
| 48、52 | u32 BOS、UNK 的 token ID |
| 56、60 | f32 层归一化 epsilon、u32 保留零 |
| 64 | 32 字节载荷 SHA-256 |
| 96 | 32 字节保留零 |

载荷先是 V 个 u32 Unicode 标量；特殊 token 写为 `0x110000 + token_id`，BOS/UNK 必须为特殊 token。普通标量禁止零、代理项和重复。随后按以下顺序连续存放 float32：

1. token 嵌入 `[V,D]`、位置嵌入 `[P,D]`、最终归一化 gamma `[D]`、beta `[D]`。
2. 每层依次为：归一化1 gamma/beta `[D]`；QKV 权重 `[3D,D]`、偏置 `[3D]`；注意力投影 `[D,D]`、偏置 `[D]`；归一化2 gamma/beta `[D]`；扩展权重 `[F,D]`、偏置 `[F]`；收缩权重 `[D,F]`、偏置 `[D]`。

线性权重按输出行存放。注意力缩放为 `1/sqrt(D/H)`，使用左侧因果遮罩；GELU 为 tanh 近似。输出投影与 token 嵌入共享，没有额外偏置。载荷浮点数量为 `V*D + P*D + 2*D + L*(4*D*D + 2*D*F + 9*D + F)`。

版本 2 保留同一张量顺序和字符词表。仅 token 嵌入及各层 QKV、注意力投影、扩展、收缩矩阵使用 INT8；位置嵌入、归一化、偏置保留 FP32。每个量化矩阵先存 `rows` 个正数 FP32 scale，再存行优先的 `rows*columns` 个有符号字节。还原值为 `q*scale`，零点为 0，q 仅允许 -127..127；整行零权重的 scale 为 1。scale 有限且不超过 `10000/127`。加载时矩阵常驻字节数组，按行计算点积后乘一次 scale，不展开为完整 FP32。激活、KV 和累计分数继续使用浮点。

矩阵元素总数 `M=V*D+L*(4*D*D+2*D*F)`，scale 个数 `R=V+L*(5*D+F)`。版本 2 载荷长度为 `4*V+M+4*(原浮点数量-M+R)`；所有大小、摘要、保留位和有限值约束仍须校验。旧版本引擎不能读取版本 2，须与模型成套更新。

转换已有自有 FP32 模型：`python tools/data/character_model_format.py --input FLOAT.coral --output INT8.coral`。不覆盖源文件或已有输出。INT8 主要节省包体和常驻内存，SSE2/标量实现可能比优化后的 FP32 内核慢，需要在目标机器上评测。FP32 点积采用多累加器；INT8 点积在 SSE2 上按块扩展符号后计算，未要求 AVX2。

层数 1–8，D 不超过 512，H 整除 D，F 不超过 4096，V 不超过 32768，P 不超过 2048。所有权重须有限且绝对值不超过 10000。每次最多评分 128 条候选，单条最多 64 字，前缀树节点最多 2048；不支持的候选返回 NaN，批次失败不提交半成品。

## 验证与诊断

`coral_character_probe MODEL [BAD_MODEL]` 从标准输入读取 `前文<TAB>候选`，输出原始神经分数；传入坏文件时还检查重载失败后继续使用旧模型。使用 `MODEL --batch` 可在一行输入多个以制表符分隔的候选，验证前缀共享、分支回溯和内存开销；标准错误报告权重存储字节数。公开测试以手写小网络的独立概率验证数学和资源拒绝，并验证模型能改变内部路径选择。

`CORAL_CHARACTER_TRACE` 可指定诊断 TSV 的绝对路径，记录输入、前文、原路径序号、候选文字、基础分数、神经分数、加分。启动时“智能候选”关闭、未满足字数门槛或没有可重排对手时不写记录；参与重排组中的短候选记为 NaN、零加分。它会包含输入正文，只在显式设置时写入；需要可由评测进程写入的目录。预热及重复解析会重复记录，不将行数当作独立样本数量。

准确率使用 `coral_parse_bench` 的最终输出评估，同时比较诊断中的内部目标覆盖、纠正和误伤。模型参数不能根据验证组结果反向选择。5–8 字命中率与实际 TSF 交互、长句和混输体验分别记录，实验结果放在公开仓库外。
