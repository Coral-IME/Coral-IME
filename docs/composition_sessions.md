# 会话端口与状态机

第五批 B1 将会话契约放在 `coral::composition`，SessionPort/SessionResult/SessionSettings/SessionToken 替代历史端口名称。公开入口是 `include/coral/composition/session_port.h`；函数、会话字段及按键/状态枚举按开发准则命名，枚举线值保留。CSW4 和 renderer 的既有字节布局未修改，协议仍为版本 4。

## 职责

`coral::composition` 静态 target 只编译状态机，依赖公开类型和标准库。CompositionSession 接收共享所有权的 CandidateSource；该接口提供候选查询与学习记录。人工查询源可以独立验证会话，无需 Windows、词典、注册表或共享设置。

`modules/runtime/candidate_source_bridge.cpp` 提供默认构造使用的词典适配器。它负责既有查询入口、显示标签、候选前后空白处理和学习调用。默认构造与本地端口随实际宿主/测试编入，平台无关 target 不编译此适配器。词典解析、评分、学习算法和文件格式没有重写。

## 状态转换

- 每次输出包含当前组合文本与候选页；提交文字与显示标签分开。
- 部分选择按候选拼音移除输入前缀，忽略分隔符，保留剩余输入与已提交条件，然后查询新页；全部转换后清空组合和条件。候选拼音与输入不匹配的特殊模式沿用一次性消费全部输入的行为。
- reset/Escape 清空输入、条件和候选，保留已设置的页大小。页大小范围 1—512。
- 查询返回 false 时保留请求输入，清空候选；不会继续选择上一次输入的候选。查询源抛出异常时不提交新输入或部分选择状态。学习调用发生在查询新页之前，其外部副作用不保证回滚。
- 翻页使用 64 位中间值检查溢出；不存在下一页时不继续查询。越界选择和非法查询参数保持原状态。Ctrl/Alt 组合键不消费，错误数字选择在存在输入时消费。

部分选择和完整候选快照属于实际状态机修复；不能把此处行为与算法目录的名称迁移混为一谈。辅助输入仍由既有词典适配提供。

## 本地端口

LocalSessionPort 使用同一二进制内共享的锁串行访问全局解析器、模型缓存和解析 arena，替代各端口独立锁。该锁不跨进程或加载模块共享；当前仍只允许一个活动引擎，不能据此接口创建两个独立引擎，也不支持并行解析。会话令牌在该模块内单调分配、不同端口不重复，耗尽后返回 0。关闭会话可重复执行。

每个会话保存独立配置，apply_settings 只校验并保存版本和值。执行其他操作时刷新持久快照，再用线程内作用域覆盖配置与全半角/简繁模式；正常返回和异常退出均撤销覆盖。没有显式配置的会话读取持久快照和进程默认模式，不继承前一会话的临时值。其他线程看不到请求覆盖；请求期间发布的新持久快照保留，当前请求仍使用自己的配置，退出后读取最新持久值。作用域仅供同线程同步请求，不把配置传播到后台任务。

本地接口与线接口一样限制页大小、模式、候选索引、Unicode 标量和模糊选项数。本地文本还拒绝内嵌零，避免旧 C 字符串入口静默截断；offset+page_size 必须在 int 范围内。未知会话、停止后的核心、非法参数和操作异常分别返回明确状态。

SessionSettings 保存完整 64 位 revision；同会话的旧 revision 拒绝，新 revision 即使值相同也保存。配置成功回复的 value 不用于回传 revision，应使用 request_id 关联。候选标识包含会话、位置以及带长度的文字和拼音，避免拼接歧义；它仍是 64 位内容指纹，不承诺无碰撞。

线协议允许模糊选项最多 64 项；当前词典适配只接受空列表或 19 项，空列表规范化为 19 个关闭值，其他长度在进入解析器前返回 ProtocolError。这是既有解析器要求的适配边界，不改变词典算法。

`make_local_session_port()` 借用已经初始化的引擎，不负责关闭引擎。`make_initialized_session_port(user_data_path, synchronous_load)` 成功时拥有初始化责任，析构先销毁会话再关闭加载/学习/日志工作。第二个参数是同步加载偏好，原来 appContainer 的误导名称已移除。重复初始化返回空指针，保留正在运行的引擎；available 表示初始化状态，不保证后台模型全部成功。

B2b1 已支持关闭后重开，实际解析器与模型重建、配置和简繁路径重新绑定。每个本地端口仅绑定构造时的运行代次，旧端口和旧会话不会恢复可用；启动前的借用端口需重建。过期拥有者析构不能关闭替换实例。直接内部操作不自动受本地端口锁保护，调用方须串行管理，模型/配置借用引用不能跨重建保留。见 [模型重建](runtime_reconstruction.md)。

## 验证与剩余接口

composition_contract 使用人工查询源检查部分提交、查询/学习异常、翻页、输入、无效参数、失败候选清理和焦点重置。local_session_port 使用人工演示实际运行两个端口中的三个会话并发请求，检查显式简体/繁体与默认配置隔离、稳定候选标识、旧配置拒绝、重复初始化、正常析构关闭及借用端口检测停止；请求仍在锁内串行解析。另检查配置/模式作用域的嵌套、异常恢复、线程隔离及作用域内持久快照更新。

生产宿主仍通过旧 DLL API 调用词典。本轮保留旧导出，并新增 runtime_ready 状态探针；旧 STL ABI 尚未移除。CSW4、TSF 与 renderer 已同步新名称，但生产宿主的会话归属、跨进程关闭和模型重建留给第五批 B2。既有强制退出测试不构成正常退出证据；新增本地端口测试通过明确析构正常返回。

当前验证数量、保留项和下一批状态见 [迁移计划](code-separation.md)，映射见 [会话迁移表](composition_migration.json)。

第五批 B2a 更新：默认适配已改为进程内 coral::runtime 操作，旧引擎 DLL 与状态探针导出均不再提供。前文 DLL 状态是 B1 验收的历史范围；当前静态边界见 [静态核心](static_engine_core.md)；B2b1 已完成进程内模型重建，生产宿主归属和跨进程关闭由 B2b2 继续。

B2b2 更新：生产宿主绑定管道实际进程/client_id/代次，固定工作槽和会话数量，回收死亡进程；普通查询、并发、慢连接退出和直接替换重连均经真实多进程测试。旧的 SessionHost 外壳不再使用，已删除。完整 TSF 焦点与特殊输入仍待平台专项，见 [宿主生命周期](session_host_lifecycle.md)。
