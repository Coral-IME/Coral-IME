# 代码与数据边界

正式词库条目、词频和概率、训练模型参数、原始语料、评测输入及相关打包产物在候选之外。公开工具不自动附带正式输入。

| 内容 | 位置与安排 |
|---|---|
| 产品代码 | `src/`，保留主要结构 |
| 公共配置与双拼 | `resources/config/`，未带入真实用户内容 |
| 产品图标 | 产品资源目录及 `resources/icons/` |
| 演示输入与生成入口 | `samples/demo/`，人工构造，MPL-2.0 |
| 演示生成物 | 构建目录 `demo-runtime/`，不写回源码 |
| 正式数据与语料 | 外置独立管理，未进入公开候选 |
| 正式脚本 | tools/data/、tools/checks/、tools/release/；旧入口转发，输入输出显式指定 |
| 第三方字典 | 独立核实来源许可，不能因在私有区就认定为项目专有 |

用户密钥及私人常用语/自定义内容模板不随源码提供；更新服务使用已确认的官网 HTTPS 地址，翻译凭据由用户自行填写。在线词库默认未配置，语音入口屏蔽。普通配置结构保留，联网及本地保存说明见 [隐私政策](legal/隐私政策.md)；不能用“模板无密钥”推断全程序不联网。

演示包含 24 条中文词条、3 条英文词、5 对 bigram、少量部首/笔画/符号及 3 对简繁映射。纠错和字符模型采用合成均匀统计，不从正式数据裁切。`demo-manifest.json` 记录输入和运行资源 SHA-256；配置另写入引擎所需 MD5。

资源根目录含配套的 `data/` 和 `config/`。`CORAL_RUNTIME_DATA_DIR` 控制构建时复制外置运行包，`CORAL_LANGENGINE_DATA_DIR` 控制测试加载目录。正式数据测试须开启 `CORAL_ENABLE_OFFICIAL_DATA_TESTS` 并指定 `CORAL_TEST_DATA_DIR`。

`tools/checks/run_isolated.py` 为每次运行创建独立用户目录与命名空间，设置 `CORAL_USER_DATA_DIR` 和 `CORAL_TEST_NAMESPACE`。默认演示不读取正式运行包。文件名相同不足以证明不同版本的词典索引与模型可混用。

正式生成清单、私有源格式适配及安装包不进入公开源码；完整入口与模型复用边界见 [数据工具](data-tools.md)。新旧正式主索引的生成路径不同，不能宣称候选行为已完全等价。
