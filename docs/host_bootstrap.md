# 产品标识与宿主启动

第六批 B，2026-10-14。`resources/product_identity.json` 是运行期程序、服务桥接、配置注册表和宿主/绘制对象前缀的维护入口。`tools/checks/product_identity.py --write` 生成 C++ 头、CMake 输出名、NSIS 和 PowerShell 数据；不加参数则检查生成物一致性。生成物进入源码仓库，构建不依赖外部产品或安装状态；校验允许 Git 换行转换。

## 标识范围

本批保留现有产品值，包括历史注册表名称；集中引用属于结构整理，不代表相关注册表/服务/诊断实现已重写。C++ 使用方通过 `coral::product_identity` target 获得头路径；CMake 产品输出名、安装脚本和安装准备脚本、Python 包清单均引用同一清单。PowerShell 数据和准备脚本一起嵌入安装器。本批只解析/检查这些脚本，不执行安装或停止现有产品。

清单覆盖八个运行程序/DLL 文件名、服务名/桥接名、应用/设置/服务启动注册表路径、安装路径值名、会话管道/互斥/停止事件及绘制管道/互斥前缀。已有 `product_constants` 是主题色与字号默认值，保留原职责。COM GUID、用户数据目录、UI 品牌文案、网络/更新标识和旧 IPC 其他对象名尚未集中，不能将本批写成全部产品身份迁移完成。

## 启动边界

旧 TSF `enginehostlauncher` 两文件删除。`platform/windows/host_startup` 提供 `coral::bootstrap::ensure_host_ready` 策略及 Win32 `start_session_host` 适配，独立于 TSF PCH、COM、注册表读取实现和词典核心。TSF 工厂注入安装状态、安装目录读取及既有服务 RPC。绘制启动器仅更新受限进程检测引用，未重写其调度。

策略先探测已有管道，已就绪时直接成功，零预算也可读取现状。探测失败属于不可重试错误时停止；正在安装时不启动新进程。缺失且预算为零时不启动。普通桌面优先绝对模块目录的相邻宿主，其次绝对安装目录中的常规文件；空、相对、缺失或目录路径不直接执行。受限宿主只走服务，不解析或启动子程序；普通直接启动失败时最多回退服务一次。

模块路径采用增长缓冲，超过支持上限则拒绝，不使用截断结果。`CreateProcessW` 使用显式绝对程序路径、引号包围的命令行、不继承句柄、程序目录作为工作目录及隐藏标志；线程/进程句柄由对象关闭。TokenIsAppContainer / SearchHost 检测保留原判定方式，迁入独立适配。

Win32 初次探测使用 `NMPWAIT_NOWAIT`，不把参数 0（系统默认等待）当作立即探测。路径选择、启动和等待共用起始时刻，后续探测最多等待剩余预算与 25 ms 的较小值，轮询暂停最多剩余预算与 10 ms 的较小值。时间计算使用经过时长，避免截止值加法溢出。状态区分就绪、安装阻塞、启动失败、预算耗尽、探测失败和内部异常，失败不重复拉起。

这份预算只控制下一步是否执行及管道等待。已经进入的系统启动调用、安装目录回调、服务 RPC 不能被本策略强制中止；旧服务自身的等待仍保留。因此不承诺整个 API 的硬性返回时限。成功探测表示管道可连接，CSW4 握手仍由随后创建的端口验证。超时可能留下已启动宿主，不以强杀回滚启动。
