# Windows 输入期间的配置快照

## 行为与边界

TSF 激活时保留一次同步初始化，以获得用户现有配置。此后的按键、焦点、候选控制器、应用占位符和快捷菜单读取已发布的不可变配置。强制刷新只提交后台请求，不在调用线程加载 INI、重连共享配置或等待后台任务。

所有者线程通过现有分派窗口每 250ms 请求一次刷新并应用完成的快照；没有编辑文档时也能刷新。通常在随后一至两轮应用设置，这不是磁盘忙碌时的硬性时限。模型执行、引擎连接和其他逐键 IPC 的同步等待不属于本次范围。

后台任务拥有独立读取器、共享映射和 INI 视图，不访问全局 SettingsConfig 的可变解析器。共享读取使用 open_read_only，不创建共享内存、不取得写互斥体；固定根对象使用不写分配器锁的查找，再校验布局、索引和完整快照。一次读取返回同一稳定代次中的全部共享配置。

不能连接共享内存时可以使用完整 INI。共享数据仍在写入、校验失败、文件不可读、缺少 settingsconfig 节或读取前后版本变化时，保留最后成功的快照并在后续周期重试。共享配置与 INI 分别发布，跨两通道不是一个原子事务；稳定性复查不能消除两次独立写入之间的全部过渡窗口。

后台按共享代次和文件修改时间跳过未变化配置。INI_ONLY 字段与应用占位符也通过文件修改时间更新。单个 ConfigAuthority 在停用、重新激活之间也共用一项在途额度，旧慢读未结束时不叠加新任务；同一进程的多个 TSF 服务对象各自拥有快照。

任务不持有 TIP、COM 或窗口指针，只持有独立状态。停用时撤销发布资格，关闭所有者线程的定时任务；在途读取结束后自行释放状态。任务持有 DLL 加载引用，系统在线程池回调返回后释放引用，因此宿主退出不等待磁盘。该方式不创建 detached 线程，也不在 DllMain 中汇合工作。它不承诺取消已经阻塞的文件系统操作。

默认值和中英、全半角、简繁的运行状态规则保持。后台线程不调用引擎，设置仍由 TSF 所有者线程应用。菜单中的显式配置写入沿用原有保存流程。

## 共享内存不可用的场景

这里主要指某个应用里的 TSF DLL 无法建立连接，不代表整台机器内存不足。

1. **受限进程先启动，对象尚未创建。** AppContainer 不创建配置共享内存；还没有其他珊瑚进程创建对象时，连接会失败。受限宿主还可能无法访问用户 INI，这时保留已有配置或首次初始化默认值。
2. **访问权不足。** 原初始化需要打开共享映射和配套互斥体，任一访问失败都可能阻止连接。本次后台读取不再要求写互斥体，但仍须有映射读取权限。管理员或低权限进程不等于必然失败，需看实际权限和令牌。
3. **初次连接遇到初始化锁争用。** 原初始化最多等待命名互斥体 100ms。超时后本次失败，后续可以重连。后台只读连接不等待这把写锁。
4. **新连接遇到未完成或无效的数据。** 根对象、尺寸、对齐、初始化标志、索引或槽位检查失败时拒绝连接。不同布局版本混用是可能原因之一，但“刚升级”不能单独作为证据。

已成功连接后，正常写锁争用不使 getGeneration 自动失败；它也会返回写入中的奇数代次。原逐字段读取在稳定重试耗尽后可能退回本进程 INI；新版后台完整读取对奇数和不稳定状态保留上一快照。

关闭设置窗口、停止服务或结束某个引擎进程不能保证对象立即消失，其他进程可能仍持有映射。正常内存压力或普通窗口切换也不应直接等同于共享配置不可用。

## 现场复现与诊断

以下场景需安装当前构建后实际验证，不能推断某个 Windows 版本的搜索进程一定进入回退。

1. 记录 Windows 版本、应用名、位数、是否提权和所加载 DLL 的构建版本。
2. 重新登录后，先在 Windows 搜索等受限宿主输入，再打开普通编辑器对照。通过来源诊断确认，不能只凭窗口类型判断。
3. 在普通编辑器、浏览器、WPS/Office、搜索和管理员终端中交替输入；在设置窗口改变候选数量、主题与工具栏开关，确认最终一致且运行模式没有被重置。
4. 在隔离测试环境让 INI 读取变慢或让首次连接碰到初始化锁。比较后台与按键配置阶段；“磁盘很忙”本身不足以定位原因。
5. 刷新期间关闭宿主或切换输入法，随后重开；旧任务不能更新新激活状态。

诊断沿用 CORAL_INPUT_TIMING=1，需在启动目标进程前设置。采集入口见[输入耗时](input_timing.md)。

| 阶段 | 含义 |
|---|---|
| tsf.config_background | 后台读取总耗时，其线程 ID 应区别于按键线程 |
| tsf.config_file | 文件时间查询耗时；result=0 成功，非零为文件系统错误码 |
| tsf.config_source | result=1 已连共享映射；result=0 尝试 INI 回退；不表示整份快照已发布 |
| tsf.test_config / tsf.key_config | 原按键配置阶段，用来确认后台慢读未传回按键线程 |

文件属性查询失败时，本轮不会继续尝试共享读取，因此可以只有 config_file 和 config_background。诊断不记录文件内容、真实输入或凭据。采集后关闭开关并重启测试应用。

## 自动验证

config_snapshot 使用隔离对象名和用户目录，覆盖后台加载器被卡住时连续一万次快照读取、单项在途任务、调度失败、读取异常、空结果、内容不变、停用与销毁、实际线程池回调、没有共享映射时的 INI 回退、映射稍后出现、INI 暂不可读后的恢复、存储策略以及应用专用占位符。

shared_preferences_boundaries 验证稳定共享快照与代次，并验证非法共享字节被拒绝时输出不变。测试不操作已安装配置，不安装或注册输入法。自动验证不替代真实宿主输入、首次登录、安装和升级验收。
