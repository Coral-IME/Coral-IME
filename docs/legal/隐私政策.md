# 珊瑚输入法隐私政策

- 文本版本：2026-10-21 发布候选文本
- 生效时间：首次正式发布时生效，具体日期随正式发行公告公布
- 提供者/个人信息处理者：个人开发者（公开署名：Coral-IME）
- 隐私及用户联系邮箱：coralime@126.com
官网：https://coralime.cn/

本政策说明随附本文件的珊瑚输入法及官网、更新服务如何处理数据。正式发布前提供此文本供查阅，不表示旧测试包已经具备新版本行为。普通拼音输入在本地完成；**本软件同时提供默认开启的更新检查和由你主动使用的云翻译，不能整体称为“不联网的离线软件”。**

## 1. 普通输入与本地保存

普通拼音输入、候选生成和本地自学习不需要注册账户或连接服务器。开发者不会仅因这些文件保存在你的设备上就获得远程访问权限。

| 内容 | 用途与范围 | 保存及控制方式 |
|---|---|---|
| 当前输入 | 在内存中处理拼音、候选和选词，并把确认文字提交给当前应用 | 使用云翻译时，主动提交的中文候选/已选前缀另按第 3 节处理 |
| 用户词库、自学习及候选规则 | 保存词条、检索键、使用次数/顺序、候选规则等，用于本地排序 | 自动学习历史默认容量上限 100,000 条；不是按固定天数保留，可在设置中清除 |
| 设置与常用语 | 保存按键、外观、输入方案、常用语和自定义输入码等 | 本机保存至你修改、删除或清理相关文件 |
| 剪贴板历史 | 默认开启时监听复制的文字，可能涉及其他应用中的内容，保存文字及时间供选择输入 | 明文保存，最多 100 条，每条最多 20,000 个 UTF-16 代码单元；读取/显示时筛除超过 90 天的记录。关闭不等于清空，软件未运行时不保证到期自动删除 |
| 本地运行日志 | 保存模块状态、错误、时间、进程及文件路径等；随日志级别或错误路径，可能含拼音、词条或输入片段 | 按大小和数量轮转。公共配置模板为每个进程文件约 10 MiB、2 份轮转备份；缺少该配置时回退为 5 份。不是所有进程合计上限，也不按一年自动删除 |
| 崩溃转储和诊断包 | 本地记录异常、线程、模块和内存片段；诊断包仅附本次转储及基础清单 | 默认只保存本机，不自动上传、不扫描重试旧报告，不附带已有日志；没有统一按天清理期限，可主动删除 |

软件会尝试尊重部分“不要记录剪贴板”标记，但不能识别全部密码或敏感内容。剪贴板、日志及转储可能包含个人信息或宿主应用内容；转储不能视为匿名化数据，词库的二进制格式也不代表加密。

## 2. 更新检查和下载

官方构建默认启用官网 HTTPS 更新服务，“自动检查更新”设置默认开启。用户进程启动约 60 秒后开始调度，此后通常每 24 小时最多自动检查一次；手动检查不受此间隔限制。你可以在设置的“关于”页关闭自动检查，仍可手动检查。

检查请求访问 `https://coralime.cn/api/v1/version/latest`，本机版本比较在客户端完成，不在该检查 URL 附加你的输入、个人词库、剪贴板、密钥或硬盘设备标识。发现新版后由你点击下载安装，取得固定版本地址并下载、校验安装包；不会仅因检查发现新版就自动安装，系统安装授权仍由你确认。下载期间可以取消，缓存可能保留在本机临时目录以供后续使用；关闭自动检查不等于删除已下载缓存。

官网及更新服务器使用阿里云中国杭州地域。服务器为提供服务、排障及安全运维可能接收/记录来源 IP、请求时间、访问路径和状态、请求提供的浏览器/客户端信息等连接数据。**开发者控制的访问日志最多保存一年，必要时提前删除；期限届满删除或匿名化，法律另有要求的按其要求处理。** 这些日志不包含由客户端主动附加的输入记录或个人词库。

## 3. 你主动使用的云翻译

翻译默认关闭。你自行开通阿里云机器翻译并在设置中启用、填写 AccessKey ID/Secret 后，触发翻译快捷键会把当次待翻译的中文候选/已选前缀、源/目标语言及必要请求字段通过 HTTPS 直接发送至阿里云机器翻译接口 `https://mt.aliyuncs.com/`，用于取得译文。普通输入不因开启翻译开关就整段自动上传。

请求由你的 AccessKey 签名，包含用于鉴权的 AccessKey ID 和签名；Secret 不作为待翻译正文发送，也不经过开发者官网中转。开发者不会通过本软件代收翻译原文或译文。第三方服务会获得网络连接信息，数据处理、保存期限和费用按你开通的阿里云服务规则执行，不能将官网日志的一年期限理解为对阿里云机器翻译数据的保证。

ID/Secret 使用 Windows 当前用户的数据保护机制加密后保存在本机配置，使用时需在本机内存中解密；不写入共享设置或产品日志。关闭翻译不等于删除凭据；清空两项并保存可移除已保存的本机凭据。请勿翻译无权提供、含密码或其他不宜提交给第三方的内容；停用翻译不影响普通输入。第三方说明可查阅 [阿里云机器翻译文档](https://help.aliyun.com/zh/machine-translation/)。

## 4. 官网访问、反馈与第三方渠道

客户端“问题反馈”只在你点击时通过浏览器打开官网，不附带输入内容、设备标识或版本参数。官网反馈功能在当前页面生成可编辑邮件草稿，由你的邮件应用发送至 **coralime@126.com**；网站本身不直接发送邮件，也不自动上传截图或本地文件。

你可以填写反馈描述、输入法版本、系统、相关应用及联系方式；草稿还可包含当前网页的来源和路径，不包含网址查询参数或片段。草稿仅在当前页面内存中保留，刷新或离开页面后清除。只有你主动发出邮件，开发者才会收到所发正文、地址和附件。

反馈由个人开发者 Coral-IME 本人处理，只用于回复、排障和必要的服务维护；**开发者保存的反馈邮件及附件最多保留一年，问题处理结束且不再需要时可以提前删除，期限届满清理；法律另有要求的除外。** 不将反馈用于广告画像或模型训练。请优先提供不含隐私的复现步骤；附日志、截图或转储前先检查内容。

邮件使用 126 邮箱服务，该服务的基础设施及独立处理规则以其政策为准，不能据官网部署地域推断邮件存储也在杭州。你主动访问 GitHub 或加入 QQ 群时，相应平台按自身规则处理数据，群消息可能被其他成员看到或保存；反馈邮件的一年期限不覆盖第三方或群成员保存的副本。不要在公开 Issue、群聊或仓库中发布私人词库、剪贴板或转储。

## 5. 当前未启用的功能与已删除行为

当前发行准备版本屏蔽语音入口，不创建录音/识别工作线程；在线词库服务默认未配置而禁用。以后启用录音、云识别或在线词库前，需要更新对应告知和选择入口，不能仅凭本政策预先授权未来的数据提交。

旧设置后台请求及硬盘序列号派生标识的生成/发送已删除，开发用输入过程记录也已删除；当前版本不再新建或追加旧 `record` 文件。旧版本已生成的文件不会自动迁移或清理，仍加载旧版本的应用需退出重开后才使用新代码。

崩溃诊断目前没有内置上传入口。未来如增加提交，应先明确接收者、文件与字段、用途和保存期限，并由你逐次主动确认；安装同意、发生崩溃或重启本身不授权上传。

## 6. 本地文件、清理和你的选择

Windows 下通常保存在：

- 设置、常用语、用户词库及规则：`%USERPROFILE%\AppData\LocalLow\coralpinyin\`，配置在 `config`，学习历史通常为 `user_history.coral2`。
- 剪贴板历史：上述目录下的 `clipboard\history.txt`；日志位于 `log\APP`、`log\TSF` 等子目录。
- 本地转储/诊断包：`%TEMP%\CoralPinyin\diagnostics\report_<随机编号>\`。
- 更新缓存位于本机临时目录内的程序更新子目录；删除前先关闭更新窗口并等待任务停止。
- 旧版输入过程记录可能残留于 `%TEMP%\CORAL Input Method\record\`，当前版本不再生成。

可以在设置中关闭自动更新、翻译和剪贴板历史，管理/清空剪贴板及用户词库。清除用户词库不同时删除剪贴板、日志、旧输入记录或转储；停用功能也不等于删除已有文件。

对无界面清理入口的本地文件，可先切换其他输入法、退出软件并关闭仍加载本软件的应用，再按需备份、删除。卸载不表示所有个人数据、更新缓存或系统备份都已清除。上述本地文件保留规则与开发者保存服务端日志/邮件的一年期限分别适用。

涉及敏感个人信息或不满十四周岁用户的信息时，请优先避免提交，并由开发者按实际场景履行必要的告知和监护人同意等要求。开发者不要求以提交此类内容换取普通输入功能。

软件本地数据主要依赖操作系统账户及文件权限保护，不承诺全部加密、匿名化或绝对安全。新增联网功能、接收者或数据用途时，将更新本政策并说明变更，按适用要求重新告知并取得必要同意。仅更新文本或继续使用不构成对新增上传的概括授权。
