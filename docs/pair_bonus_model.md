# 独立词对增益模型

`CBGN0001` 是常规可编辑词对增益格式，沿用运行资源名 `languagemodel.coral`，由 magic 分派，兼容保留旧 `CSLM0001`、`KNAGBIN1` 读者。它保留纯词库基础排序，仅对显式词对增加有限奖励；不保存一元、回退概率、主词库摘要或词条分词序列。模型质量与格式验收分开，历史回归收益不代替新鲜独立验证。

## 编辑与编译

输入是 UTF-8 TSV，必需列为：

```tsv
prev_word	next_word	bonus
甲	乙	0.5
乙	丙	0.25
```

数值是固定自然对数尺度的排序增益，范围 0–64，不能直接填旧模型的完整条件对数概率或质量分。词面精确匹配，拒绝空词、控制字符、重复词对、非有限数和越界值；不隐式合并简繁或读音。

```powershell
python tools/data/build_pair_bonus.py pairs.tsv candidate.coral
```

编译不读取词库，不重新估计其他词对，输出路径必须不存在。删除一行再编译，该项奖励变成零，保留项的 f32 值保持不变。用户应保存文本源；二进制内部编号不属于编辑接口。此版支持完整词对源的重编，尚未增加个人覆盖文件或设置页编辑器。

候选资源应在隔离目录配套更新 `BigramGBin` MD5，再加载。模型加载校验通过后才替换旧资源，失败保留之前的可用模型。初次失败由既有引擎无模型路径处理并记错，评测不得把加载失败当作空表成功。

## 常规打包

`tools/release/prepare_optimized_runtime.py check --pair-bonus-source <pairs.tsv>` 在清理、编译程序前编译完整词对源，将二进制冻结到工作目录的 `model-inputs/`。`--source-runtime` 仅提供现有词库、纠错及配置资源，不需要其旧概率模型与新词库绑定。词对源和资源的摘要写入 selection；构建期间输入变化时，`stage` 拒绝继续，要求重新预检。

`stage` 将冻结的增益模型与当前主词库收集成运行资源，核对原生模型读者，再交给 `package_windows.py --precompiled-tables-storage compact`。安装包使用新版 `coral_table_restore` 原样还原模型并逐文件校验，不能用旧版本还原器解释新容器标志。打包保留已有 GPT2 文件和产品开关，二元优化评测仍默认关闭 GPT2。

因此日常修改只需要编辑 TSV，然后照常调用打包入口；不用重建 LM 一元、回退或 phrase→token 映射。改变词库编号时只重载进程内词面缓存。

## 评分与搜索

每条组句路径的分数是纯词库基础分加各边界的显式增益。一个完整词库词条不拆开计算内部奖励。不存在于增益词面表的内容、中英混输边界清除上下文，不能跨过未知内容接词对；句首如有 `<s>→词` 条目则显式参与，否则为零。跨次上屏只按既有条件强度缩放第一条外部奖励。

完整输入精确命中词库的直出规则继续保留；不能凭奖励推翻该规则。非完整词的直选和组句搜索使用一致的外部奖励。基础词频、模糊及编辑惩罚沿用纯词库路径，不叠加 surface 模型的读音先验。

[连续输入的前缀稳定](prefix_stability.md)仍在本路径的搜索中叠加：七字内不罚，第八字起对改写稳定锚点施加有上限的惩罚，强模型证据仍可翻转；退格、模式变化和会话重置沿用原规则。它不写入词对表，也不因模型文件格式改变而关闭。

正奖励可能使原始代价为负。实现使用 `c'=c_base-bonus+K*(to-from)`，K 为当前模型最大增益，每条完整路径添加同一个常数。搜索启发值按每个后词的最大入边奖励构造，输出分和最短路径代价减回势差，不把负代价截成零。仍保留现有 Top-K、去重和展示预算，不声称穷尽全部语言候选。

运行时从当前主词库建立 phrase ID→词面状态缓存，只为跨次上下文查询加速；缓存与本次加载一起提交。词库换号后重载缓存即可，词对二进制不需要重编。词库可达词面或排序变化仍会改变输出。

空文件表和所有增益为零的表完全退回同版本纯词库路径，不改变状态细分或跨度剪枝。启用非零奖励时关闭不安全的完整跨度捷径，避免将词库权重当作含奖励路径的上界。

## 二进制布局

字段显式小端。80 字节头：

| 偏移 | 字段 |
|---|---|
| 0 | 8 字节 `CBGN0001` |
| 8、12 | u32 版本 1、头长 80 |
| 16 | u64 总字节数 |
| 24、28、32、36 | u32 词面数、词对数、字符串池字节数、保留零 |
| 40 | 头之后完整载荷的 SHA-256，32 字节 |
| 72 | 保留 8 字节，全零 |

之后依次为：每词面 `(u32 offset,u32 length)` 共 8 字节；每词对 `(u32 previous,u32 next,f32 bonus)` 共 12 字节；连续 UTF-8 字符串池，无终止零。词面状态从 1 开始，0 表示无词面；词面对唯一，词对按端点状态严格递增。词面记录按顺序连续覆盖字符串池。

最多 200 万词面、2,000 万词对、512 MiB 文件、每词面最多 4,096 UTF-8 字节。拒绝非法 UTF-8、重复词面、非规范区段、越界、未知标志及错误摘要。摘要是完整性检查，不是发布者签名。

## 验证

`pair_bonus` 使用人工字节夹具检查编码和语义损坏，原生点查检查删除及加载失败保留。随机小 DAG 以手写奖励公式穷举核对最优代价，另检查空表与纯词库输出一致、词库换号、整词直出。

准确率评测固定词库、纠错及其他设置，默认关闭 GPT2；比较纯词库、冻结当前二元和候选。新格式是排序增益，不能用 `CSLM0001` 的行概率归一化规则验收，应检查奖励边界、搜索一致性和空表等价性。正式训练数据及模型转换、开发选择和质量结果保存在公开仓库外。
