# 连续输入的前缀稳定

组句是每次输入后的重新搜索。追加后文可以改变最优路径，但已经显示并稳定的前部不应因微小分差反复跳动。该策略仅作用于当前输入会话，不改变词库词频、一元概率、二元参数或用户学习。

## 生效范围

- 按候选源实例保存首屏返回的首选及其原始拼音覆盖范围。仅相同条件、相同全拼或双拼模式下的末尾追加沿用历史。
- **当前组合路径达到八个汉字才加罚，七字及以下不生效。** 前七字可以积累参考，但搜索代价保持原值。
- 如果词格仍存在七字以内的完整中文解释，本轮整体暂缓稳定，防止长备选加罚后间接改变短候选的神经评分名单。该门槛采用保守下界，不仅检查最终返回文字的长度。
- 参考首选的最后两个字留作可变尾部。其余锚点按同字、同拼音覆盖区间的持续出现次数增加可信度，最多四次；同一输入的重放、翻页和神经重排不增加次数。
- 退格、中部改写、条件或模式变化重新建立历史。移动编辑光标、清空、提交、选词、配置变化和显式清缓存清除历史。不同会话互不继承；缓存身份包含完整锚点，翻页亦不例外。
- 仅为能按输入音节逐字对齐、音节已经完整的汉字建立锚点。简拼声母和未完成音节不作为稳定证据；混合简拼中的完整音节与含分隔符的拼音仍按原始覆盖范围对齐。繁体显示先转为模型使用的简体；混输组句保留原评分。

## 搜索与代价

同一位置、语言模型状态和边界标记下，分词或查询别名产生的相同中文前缀只保留最低代价代表。使用增量哈希预筛后逐字节核对，不会因哈希碰撞合并不同文本；不同语言模型状态不合并。尚未生效的惩罚及封顶余量不同也不合并。被替换的排队节点不再重复展开。

稳定惩罚在路径搜索中计算，而非仅对最终一条组句换序。每个被改写锚点的原始代价增加 `0.25 + 0.125 × min(持续次数, 4)`，整条路径最多增加 `1.5`；单字强度及整句上限均为原先的一半。先累计本轮惩罚，第八个汉字出现时才计入路径代价；后续只补增量。下一次输入重新从模型原始分数计算，不把上轮惩罚写回。非负惩罚不进入原有启发式，其下界性质保留。

原始拼音字节位置由音节图保留至压缩后的词格，不能将压缩顶点序号当成输入字节数。字词切分变化不会免除对相同已覆盖区间的比较。

惩罚是有限偏好，不锁死文字。显著更强的后文仍能纠正前部；完整主词库命中继续走直接候选规则。界面仍仅保留一条最佳中文组句，其余词库候选按原规则显示。

## 验证

`surface_decoder` 使用人工图验证七字与八字门槛、减弱后的中等证据翻转、强证据翻转、完整词库优先、独立会话、回退与模式切换、压缩位置映射及重复路径挤占。`composition_contract` 与 `translation_controller` 验证选词、清空和实际控制器重置通知。

`pair_bonus` 另外在真实加载的 `CBGN0001` 增益模型上验证七字不罚、八字恢复稳定前部、强证据仍能翻转和重置后不继承锚点，图中同时包含实际命中的词对奖励。前缀稳定不依赖旧一元或回退概率。

数据质量评测须另用逐键输入序列，同时记录稳定前部的改写、正确转错误和错误转正确，以及最终准确率和每键延迟。每行清缓存的普通批量命中率只衡量无历史搜索，不能替代连续输入评测。正式语料和用户输入明细保留在私有目录。
