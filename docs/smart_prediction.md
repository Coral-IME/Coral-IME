# 智能预测

2026-10-16：在设置 → 高级的 U/V 模式之前增加“智能预测”，默认开启。旧配置没有 `smartPrediction` 键时按开启处理；关闭后当前候选立即使用空条件重查，连续输入历史同时清空，重新开启从空上下文开始。

## 输入上下文

条件来自本输入上下文中连续上屏的中文，并包含当前组串中已经选出的中文。末尾最多保留 16 个 UTF-16 单元，裁剪不拆开代理对；标点、英文等非中文字符会截断历史。例如“锄禾”上屏后再选择“日”，下次查询携带“锄禾日”，而不是只携带“日”。此历史只驻留在对应控制器中，不新增日志或持久记录。

线程失焦、前台失焦、文档或输入上下文切换时清空；查询同时核对前台窗口，作为同线程多窗口的补充。回车、Esc、标点、无组串时的编辑/空白/快捷操作，以及中英文模式切换，也会清空。翻译与剪贴板提交不续接旧中文历史。关闭开关或清理条件不重置正在编辑的整个远端组串。

## 候选生成

1. 在主词库中从长到短查询上下文的后缀，选择已收录的前词 ID，作为语言模型解码的初始状态；直接词候选也使用条件概率。词典和模型缺失相应关系时保持原有退回路径。
2. 用至少两个汉字的中文后缀匹配主词库的整词前缀。当剩余部分的完整拼音与本次输入一致时，将剩余中文作为续接候选，避免重复输出已经上屏的前缀。每次前缀搜索最多检查 2048 个索引项，最多返回 32 条。
3. 单字母输入保持普通排序，避免简拼被预测过度干扰。U/V、符号、翻译、剪贴板等输入使用各自的既有规则。繁体上下文经转换查询，续接候选经过既有繁体处理中间件；缺少反向转换资源时该次上下文查询退为空条件。
4. 条件词加入解析缓存身份，相同拼音切换条件后重新解析；分页使用相同条件。置顶、屏蔽和自定义短语仍经过既有规则处理。

### 分次输入的关联强度

2026-10-16：跨次输入的语言模型条件影响默认保留 70%，即在此前完整条件影响的基础上削弱 30%。这里的刻度是 100% 保留原始条件影响，0% 忽略外部条件；它不表示“扣除 70%”。只在解码器内部设置默认强度，不新增设置界面选项或通信字段。

折算在现有对数评分上进行：`新评分 = 无外部条件的评分 + 0.7 ×（完整外部条件的评分 − 无外部条件的评分）`。直接候选的条件加成和组句路径的跨次关联使用同一折算；本次输入内部各词之间的二元评分仍使用原始强度。前面有未入模型的中文词时，边界标记保留到真正消费外部条件，避免从该路径绕过折减。没有条件词或关闭智能预测时保持普通路径。

此强度只调节跨次输入的语言模型关系，词库整词续接及其两字门槛保留既有规则。分次输入与整段输入因此可以共享同一词对关联，但结果不保证完全相同；分词、输入范围和上下文也会影响结果。

改动仅增加评分算术与搜索节点的边界标记，不改变词库格式、协议或搜索轮次，也不增加词库查询。搜索排序会随得分变化，不能据此宣称实际耗时完全相同。此调整不保证消除已有模型中的强关联：以隔离正式资源复核，“服务 + buzijizu/buzijizuo”在 70% 强度下仍优先得到“簿自己组/簿自己做”；关闭预测仍恢复“不自己组/不自己做”。本次没有为该个例进一步调整强度或修改模型数据。

### 词库续接的两字门槛

词库续接只使用至少两个汉字的上下文后缀，减少单字可匹配大量整词前缀所带来的过度预测。例如，词库收录“啤酒瓶”时，先输入“啤酒”再输入 `ping`，可以通过整词续接优先推荐“瓶”；只输入“酒”再输入 `ping`，不会通过“酒瓶”触发这条续接路径。2026-10-16 用户确认保留此策略。

单字“酒”仍可作为条件词参与语言模型评分；“瓶”能否排第一取决于模型关联权重和其他候选的得分。两字门槛仅约束词库续接，不代表单字条件词完全无效。另外，“单字母输入保持普通排序”约束的是本次输入的拼音字母数，与前文汉字数量是两个独立条件；`ping` 不属于单字母输入。

新增的文本索引仅保存主词库条目下标，不改变词库或语言模型文件格式，也没有替换既有算法。会话配置增加 `smart_prediction` 布尔字段，帧版本由 4 升至 5，保留 `CSW4` 帧标识；旧版本明确拒绝。设置、TSF 和宿主应使用本次一起构建的程序。
