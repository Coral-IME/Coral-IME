# 源码检出与发布准备

本候选采用全新本地 Git。旧仓库的提交、远程配置、LFS 对象、正式数据和内部审计材料没有复制进来。当前没有公开远程地址；本地准备提交使用中性身份，不代表最终版权主体或发行者。

## 获取与验证

已有仓库地址后，从该地址进行正常检出；直接获取源码 ZIP 也能构建，不需要旧 Git 历史。Windows 的字节级清单核对可使用 `git -c core.autocrlf=false clone <仓库地址> <目标目录>`；普通 Git 行尾设置可能改变工作区文本的行尾，源码 ZIP 保留提交中的字节。

按照 [构建与演示](build.md) 和根 README 安装构建依赖，从检出根目录执行 Release 或 Debug 预设。Windows Visual Studio 使用多配置构建树，同一配置树也可显式构建另一种配置。当前默认测试为 54 项，不要求正式词库、正式模型、作者构建目录或原仓库资源。2026-10-14 的去重迁移在工作树中，旧源码 ZIP 与干净检出证据对应此前版本；当前变更见 [去重计划](code-separation.md)。

公开演示仅使用 `samples/demo/fixtures/` 的人工词条和合成统计。`build/`、私人配置、缓存、证书和模型输出不应进入源码提交。第三方源码、许可和自制资源是显式保留的部分，不能用只导出旧仓库已跟踪文件的方式替代当前清单。

## 发布范围

本地检出、源码导出和构建验证通过，不代表正式产品已验收。正式主索引差异、配置门闸失败、英文候选开关及 DLL 退出问题按候选状态保留；发行主体、公开源码地址、旧安装元数据和法律草案仍待确定。源码候选不包含正式词库/模型；需要它们的正式回归结果单独登记。

第六批 D 已删除诊断上传服务地址与自动重试路径，改为默认本地转储，详见 [本地诊断](local_diagnostics.md)。上表其他服务仍待各自迁移；本批不证明全程序离线。

第六批 E1 移除更新检查/下载业务的旧固定服务地址，改为默认空的 CORAL_UPDATE_SERVICE_BASE_URL 构建配置；非 UI 协调器和独立下载程序在未配置时停止请求。实际 HTTPS 服务兼容、安装及进度 IPC 身份/关联待后续，不影响上表其他模块仍需复核的事实。见 [更新接受](update_package_acceptance.md)。

第六批 E2 已重写更新请求关联、私有进程通信和有限接收/取消；E1 所列旧 IPC 后续项在本批完成相应人工回归。默认空服务不变，真实 HTTPS、安装、签名信任与校验到执行路径间隙仍待验证；其他模块的旧地址复核范围不变。见 [当前更新实现](update_private_channel.md)。

第六批 E3a 文本导入迁移不涉及网络或在线词库，后者仍有上表旧服务路径。维护者已选择下一批默认禁用在线词库、配置新服务后启用；该门控尚未在本小批落地，不能据偏好声称当前源码已禁用。见 [文本导入状态](lexicon_text_import.md)。

第六批 E3b 移除在线词库固定旧主机，CORAL_LEXICON_SERVICE_BASE_URL 默认空，管理器在未配置时不请求/写词库；当前主程序也没有注册原注释中的自动词库定时器，本批不新增激活入口。已实现维护者的默认禁用选择，E3a 历史“未落地”状态由此补充。其他模块上表地址继续复核，真实运输/服务兼容未验收。见 [在线词库](online_lexicon_catalog.md)。
