# 源码检出与发布准备

本仓库从全新的候选 Git 开始维护，原工程的私有历史、正式数据及内部审计材料不属于公开范围。当前已有仓库入口 https://github.com/Coral-IME/Coral-IME，处于公开准备阶段；本轮不改变可见性。发行者为个人开发者（公开署名：Coral-IME），联系邮箱 coralime@126.com。早期提交的中性身份不替代实际作者/发行主体声明；旧 AI 配置在候选历史内的残留仍按下文单独处理。

## 获取与验证

已有仓库地址后，从该地址进行正常检出；直接获取源码 ZIP 也能构建，不需要旧 Git 历史。Windows 的字节级清单核对可使用 `git -c core.autocrlf=false clone <仓库地址> <目标目录>`；普通 Git 行尾设置可能改变工作区文本的行尾，源码 ZIP 保留提交中的字节。

按照 [构建与演示](build.md) 和根 README 安装构建依赖，从检出根目录执行 Release 或 Debug 预设。Windows Visual Studio 使用多配置构建树，同一配置树也可显式构建另一种配置。默认官网更新开启时，客户端注册 69 项测试；接入独立服务端另增 1 项，合计 70 项。不要求正式词库、正式模型、作者构建目录或原仓库资源。2026-10-21 的提交 `d240364` 已完成独立检出、空目录 x64 Debug/Release 完整构建、各 69/69 回归及源码 ZIP 逐字节核对，见 [当前基线](build-baseline.md)。其他旧 ZIP/构建证据仍只对应其原版本；后续变更见 [去重计划](code-separation.md)。

公开演示仅使用 `samples/demo/fixtures/` 的人工词条和合成统计。`build/`、私人配置、缓存、证书和模型输出不应进入源码提交。第三方源码、许可和自制资源是显式保留的部分，不能用只导出旧仓库已跟踪文件的方式替代当前清单。
