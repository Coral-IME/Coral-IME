# Windows 语音输入

## 临时屏蔽（2026-10-20）

语音输入入口临时关闭：`platform/windows/speech/speech_runtime.h` 的 `kSpeechFeatureEnabled` 为 `false` 时，设置左侧不显示“语音输入”，悬浮栏不追加麦克风入口，主程序也不创建语音宿主、键盘监听或录音线程。设置页实现、配置项、快捷键规则、按下发言、运行时和测试均保留；既有 `speechEnabled` 配置不会绕过屏蔽。恢复时把该常量改为 `true` 并重新构建即可，不需要删除或迁移代码。

设置左侧的“语音输入”页位于“高级”下方、“关于”上方（当前由 `kSpeechFeatureEnabled` 临时隐藏）。默认关闭。开启后填写腾讯云 SecretId（AccessKey）和 SecretKey 并点击“保存凭据”。凭据使用当前 Windows 用户的 DPAPI 加密后保存到原有用户配置文件；共享设置只包含语音开关、按下发言开关、快捷键、凭据就绪标记及版本，不包含密钥。删除凭据时同时清空两项并保存；填写不完整时保留原凭据。

## 使用

默认快捷键是 **Ctrl + Win + Shift**：同时按下，松开任意一个键时触发一次。左右修饰键均支持，不限制按下顺序；加入其他按键（例如 Ctrl + Win + Shift + S）不会误触发语音。也可选择 Ctrl + Win + Space、Ctrl + Alt + Space、Ctrl + Shift + F8。快捷键在开关打开且凭据已保存时启用，由独立消息线程监听，不记录输入文字。

设置页“按下发言”区块新增 **按住 Ctrl + Win 发言** 开关，默认关闭，快捷键暂固定为 Ctrl + Win。开启并满足语音开关、凭据条件后，按下 Ctrl + Win 立即打开同一个小窗并开始采集；松开其中任一键即结束采集并进入既有整段识别流程。按下其他键会结束本次发言，避免抢占更长组合；按住期间 Win 键的松开事件会被吞掉，避免弹出开始菜单。开启“按下发言”时原“语音输入快捷键”暂停并禁用选择，关闭后恢复；工具栏入口不受影响。该设置仅在语音输入开关打开且凭据已保存时生效。

开关打开后，桌面悬浮栏在原有五栏之后追加麦克风入口；关闭后恢复五栏，按现有悬浮栏显示/全屏/焦点策略运行。点击入口、使用快捷键或按下发言均打开同一个小窗，并在凭据及麦克风可用时自动开始录音。缺少设备或有效本机凭据时显示具体提示，不启动识别。录音通过 Windows 默认可用输入设备采集为 16 kHz、单声道、16 位 PCM，全部保存在内存。

小窗首版交互：

1. 录音时显示音量与时长，最长 60 秒；按下发言时提示“松开 Ctrl + Win 结束并识别”。
2. 点击“结束并识别”可提前结束录音；按下发言模式松开 Ctrl 或 Win 即结束录音并识别，未开启时录音期间再次使用快捷键也会结束录音并识别。
3. 录音结束后一次发送到腾讯云，显示“正在识别”。不自动重试。
4. 识别结果可在文字框中修改。点击“输入文字”回到最初的输入窗口，或点击“复制”手动粘贴。“重新录音”开始下一段。
5. 点击“取消”、关闭按钮或按 Esc 取消本次操作。关闭语音开关或更换凭据同样取消在途语音任务，迟到结果不再显示。已发送到云端的处理和计费无法撤销。

输入操作会复核最初的窗口、进程、线程和焦点控件。原窗口关闭、焦点控件改变、前台恢复失败、快捷键尚未松开或系统权限阻止输入时，保留文字供手动复制；没有原输入目标时不启用“输入文字”。同一输入控件内使用恢复后的当前光标位置，不保存编辑器内部光标偏移。不自动改变剪贴板，只有用户点击“复制”才写入。

## 麦克风检测

“检测麦克风”在语音开关关闭时也可使用，无需腾讯云凭据。打开同一小窗，录制至多 5 秒并显示音量；检测完成后提示是否收到声音。检测数据不会上传或写入文件。无法打开设备时提示检查默认输入设备、其他程序占用或 Windows 麦克风隐私权限。

## 模块边界

- `modules/speech/` 及 `include/coral/speech/` 继续承担跨平台录音转文字和快捷键规则，不包含 Windows 采集或界面。
- `platform/windows/speech/` 提供 WinMM 采集、Windows 键盘监听及桌面小窗，目标 `coral::windows_speech`。
- 设置主程序在用户配置初始化后创建并持有 `SpeechRuntime`，退出时先停止监听、取消并等待录音/识别任务，再结束引擎和日志。
- 悬浮栏读取既有共享设置，通过只有“打开语音界面”含义的本地窗口消息请求常驻设置进程；不传输凭据、录音、识别文本或输入目标，不改变候选窗通信格式。测试宿主使用独立名称，避免触发用户的语音窗口。
- 原有 INI 原子替换在 Windows 下增加对共享/访问占用错误的有限重试（最多约 310 ms 等待），并以写穿方式替换；人工持有不共享删除的文件句柄后延迟释放，验证替换能够完成。

配置项为 `speechEnabled`、`speechShortcut`、`speechPushToTalk`、`speechCredentials`、`speechKeyConfigured`、`speechCredentialRevision`；默认值同步到演示配置。 `speechPushToTalk` 仅表示是否启用按住发言，快捷键固定为 Ctrl + Win，不写入共享设置中的原快捷键字段。凭据保存采用有限的本地同值事务重试，以处理短暂文件占用，提交成功后才发布共享就绪标记。

跨平台核心、命令行联调、文件限制及腾讯云 API 见 [语音基础模块](speech_input.md)。不提供流式转写、设备选择、后台长录音或识别记录。
