# 表面词二元模型实验接口

本接口将词库排序分数与语言模型概率分开。`modules/language_model` 是无 Windows 依赖的 C++17 读者；引擎仅在语言资源 magic 为 `CSLM0001` 时使用它。原 `KNAGBIN1` 读者、两条旧 CSV 构建路径及旧模型语义继续保留。新模型不能通过旧 `prob` CSV、终止词过滤器或安装端旧模型重建器转换；当前接入属于隔离实验，没有新增正式打包入口。

## 概率与词条身份

状态 0 表示没有前文，1 到 N 是唯一表面词元，含显式 UNK。读音由主词典的拼音词格约束；多个合法读音可映射到同一个表面状态，不复制计数，也不声称构成读音联合概率。

每个词元分别保存 `ln(P_token)`、`ln(P_low)` 和 `ln(alpha)`。无前文使用初始先验；二元命中使用完整条件概率，未命中使用 `ln(alpha(h)) + ln(P_low(w))`。`ln(alpha)` 可以为正。每一条件行及两套一元必须归一化，所有实际转移应为非正对数概率。

映射表将实际主词典 phrase ID 映射到 1–64 个 LM 词元。例如“怎么了”可以映射到“怎么／了”：首次转移由前文决定，内部转移完整累加，结束状态为“了”。候选结束不额外加入 EOS。功能词的、了、我、是可作为普通状态，不因字面身份终止模型。

映射必须从真实主词典中读取 `(phrase_id, word, full_reading)`，并绑定整个 `mainlexicon.coral` 的 SHA-256；不依靠词典行号推测 ID，不对显式读音失败使用首词回退。该摘要是资源身份和完整性检查，不是发布者签名。模型缺少的词条仍使用词格自带排序分数，但清除 LM 前文；中英文边界也清除前文，禁止跨过未知内容构造二元关系。

当前数据侧实验只选择训练中有证据的一/二词元主导切分；更多词元、无证据词条和读音未确认项继续回退。这是首轮可审计近似，不等同于完成词条准入、多音读音消歧或所有候选的神经分词。

## CSLM0001 文件

全部整数为显式小端定宽字段，对数是 IEEE 754 binary64。文件不包含编译器 struct 布局，区段无对齐填充、无尾部扩展。

| 头偏移 | 字段 |
|---|---|
| 0 | 8 字节 magic `CSLM0001` |
| 8、12 | u32 版本 1、头长度 128 |
| 16 | u64 文件总长度 |
| 24、28、32、36 | u32 词元数、弧数、phrase 映射数、序列元素数 |
| 40、44 | u32 UNK 状态、保留值 0 |
| 48 | 主词典 SHA-256，32 字节 |
| 80 | 头之后完整载荷的 SHA-256，32 字节 |
| 112 | 16 字节保留值，全 0 |

头之后依次存储以下区段：

1. 每词元 32 字节：f64 初始对数、f64 低阶对数、f64 回退对数、u32 弧起点、u32 弧数。状态按 1 到 N 对应记录顺序。
2. 每弧 12 字节：u32 目标状态、f64 完整条件对数。同一前词内目标严格递增，区段连续覆盖且无重叠。
3. 每 phrase 映射 12 字节：u32 phrase ID、u32 序列起点、u32 序列长度。ID 严格递增、不得重复；序列连续覆盖。
4. 每序列元素 4 字节：u32 表面词状态。

限制：文件不超过 2 GiB，词元不超过 200 万、弧不超过 5,000 万、映射不超过 500 万、序列元素不超过 1,600 万；每个映射 1–64 个词元。未知版本、保留位、非规范区段、摘要不符、重复 ID/弧、越界、非有限数、非正概率和不归一化分布均拒绝，数值质量容差为 1e-7。读者先在临时对象中验证，成功后替换，失败保留旧对象；借用期间不得重载。

## 解码和验证

候选展示保留维护者确定的产品规则：语言模型拼接的普通中文组句只展示概率最高的一条，词库直接产生的候选沿用既有召回、排序和翻页规则；既有中英混输兼容处理保持原样。内部计算多条完整路径用于择优，不表示应将这些路径全部展示。该规则用于减少低质量长组句对选词的干扰，不能将其误判为需要扩大输出数量的缺陷。

优化和开发评测优先关注 3–8 个汉字的输入，9–10 字作补充，更长输入作为低优先级压力测试。首选命中及配对纠正、误伤是组句质量的主要指标；前八命中同时受上述展示规则影响，不能单凭未展示的目标推断搜索不可达。

`ContextScorer` 根据 magic 分派；新路径在组句和直接候选中均使用同一套短语概率。跨上屏条件只折减第一次外部转移，内部转移保持完整；模糊与编辑惩罚单独保留。已知词条不再将字典排序分数与 LM 概率取最大值。

新路径对普通中文和混输都用条件概率上界构造 A* 下界。上界包括初始、命中、回退和短语内部转移。人工 DAG 的穷举对照检查的是最优原始路径代价；候选长度排序、每状态 Top-K 容量、词库召回裁剪仍有既有产品规则，不能从最优路径检查推断所有 Top-K 或实际准确率已达上限。

新格式禁用“完整词条命中后省略内部区间查询”的旧捷径：完整词条概率不是其他组合路径的上界。旧格式仍保留该策略和 `CORAL_SPAN_PRUNE=0` 诊断开关。逐区间取词数与最终候选组装预算仍需独立审查；禁用此捷径不等于召回已完整。

独立构建不需要主工程或输入法资源：

```powershell
cmake -S modules/language_model -B build/lm-standalone
cmake --build build/lm-standalone --config Release
ctest --test-dir build/lm-standalone -C Release --output-on-failure
```

原生 `coral_lm_probe MODEL LEXICON` 启动时完整校验；标准输入每行 `S context_state token_state` 查询词元，或 `P context_state phrase_id` 查询短语。输出仅含分数/状态，未映射短语输出 `unmapped`，无输入可用于纯校验。Python `tools/data/surface_model_format.py` 提供内存和流式编码，编码后仍须原生读回，不能把写文件成功当作语义验证。

人工夹具覆盖两套一元、命中、正回退、多词元和多读音共享状态、损坏资源、失败保留旧模型；引擎夹具另覆盖未知词断开、直接候选、条件强度及 80 组 DAG 对照。正式训练、词条证据、真实开发/盲测输入和模型产物均位于公开仓库之外。

逐区间取词上限曾进行取消试验。虽然部分正确路径恢复可达，开发对照未见首选收益且出现新增误伤，故未保留该运行时改动；默认策略保持原样。该上限与条件概率排序不同序，不能视为概率安全剪枝，后续应先审查评分尺度及缺少映射的回退，再重新评估。
