# 文本服务会话桥接

第六批 A，2026-10-14。`platform/windows/text_service` 提供 `coral::text_service::SessionBridge`，通过注入的端口工厂连接宿主；该静态库不链接词典核心、注册表、TSF COM 或预编译头。生产工厂独立编译在 TSF 目标，继续调用既有 launcher。启动等待预算 2000 ms，恢复启动预算 50 ms，生产管道端口交易预算 75 ms；这些不是模型执行的硬性中止时限。

## 所有权与名称

两阶段候选在基础查询成功时记录 UI 版本与其对应的传输请求编号。`refine` 和 `cancel_refinement` 必须匹配这对标识；优化轮询不执行连接恢复或重放，失效、失败和无结果均保留基础候选。后台模型不占用桥接锁，轮询只启动工作、检查完成状态或接收已经评分的结果。控制器的 120ms 停顿定时器和 25ms 轮询均在所有者线程管理；收到结果后还要检查输入/优化代次和前台窗口。提交、导航、编辑、隐藏或会话变化立即停止显示侧接收；显示内容实际改变时递增显示版本，使旧渲染器操作失效。详见 [字符模型](character_language_model.md)。

`SessionBridge` 持有端口和逻辑会话，互斥锁串行化所有调用；工厂与端口不得回调桥接对象。逻辑编号仅在本对象内有效，成功打开远端会话后分配，关闭后不会再次使用。传输请求编号独立递增，耗尽后拒绝；零不是有效编号。远端令牌更换不影响界面持有的逻辑编号。替换端口由旧端口析构清理所属租约，见 [宿主生命周期](session_host_lifecycle.md)。

旧 `EngineCoordinator`、`CandidateDataSource`、`CandidateQuery`、`CandidateViewSnapshot` 分别迁为 `SessionBridge`、`CandidateProvider`、`CandidateLookup`、`CandidateSnapshot`；方法、私有成员和快照字段采用开发准则的命名。旧文件与无人调用的 `queryIfCurrent` 删除。完整映射见 [迁移表](text_service_session_bridge_migration.json)。

## 失败与恢复

| 操作 | InvalidSession | Unavailable | Timeout / ProtocolError |
|---|---|---|---|
| 候选读取 | 重新连接，恢复配置后重试一次 | 重新连接，恢复配置后重试一次 | 原样返回失败 |
| 学习、撤销、规则、清缓存、词库刷新、重置、配置写入 | 明确拒绝执行，恢复后重试一次 | 返回失败，丢弃失效端口；下一次独立调用可连接 | 返回失败，不重放本次操作 |
| 远端会话创建/已确认配置恢复 | 可恢复失败最多连接一次 | 可恢复失败最多连接一次 | 保留具体错误，停止业务操作 |

一次调用最多成功更换端口一次，预备恢复和业务重试共用这份额度。失败的替换保留原端口。未知或已关闭的逻辑会话直接返回 `ERROR_INVALID_HANDLE`，不会尝试恢复。超时、断线或无效回复不能证明操作没有执行；不会在下次调用补发失败的业务操作。

配置以最后一次成功回复为本地恢复依据。即使值相同，较新的 revision 也会发送；旧 revision、候选上限越界和非空但不是 19 项的模糊音配置在本地拒绝，不通过重连绕过版本检查。同版本不同值沿用核心允许的行为。写入失败不覆盖已确认配置；配置回复超时或无效时，关闭有不确定状态的远端会话，后续另开会话恢复已确认配置，不在当前调用重新连接。断线则释放端口，其余逻辑会话在下次访问时按各自已确认配置恢复。

候选快照先完整构造再提交，错误或异常保留调用方原输出。快照 request_id 表示界面查询版本；它与内部传输 request_id 分开。实际候选工作线程仍由 `CandidateController` 在应用结果时检查界面版本；本批没有重写窗口与工作线程生命周期。

## 验证范围

`text_service_session_bridge` 以人工端口验证读取和七类修改操作的失败分类、最多一次重试、无延后重放、配置版本、恢复失败、多个逻辑会话的延迟配置恢复、关闭与输出保留。`session_host_process` 还使用真实宿主和独立客户端进程：同桥接对象保留简体/繁体两个会话，宿主正常退出并替换后恢复各自配置，拒绝旧版本，析构后验证宿主容量可用。

这证明桥接与普通桌面宿主之间的行为。完整 COM 焦点、组合文本、真实 Search/AppContainer、剪贴板/UI 生命周期，以及产品标识集中和 launcher 重写仍待后续批次；词典算法、模型/词库格式保持原样。

本批 x64 Release/Debug 全量构建及默认回归各 37/37，Win32 核心、管道端口、资源工具、桥接与 TSF 构建通过；两个配置的真实宿主测试均以正常停止完成，无强制清理。65 个词典 C++ 文件、27 个既有演示、2,600 个第三方及 483 个只读对照文件哈希不变。未安装、签名或发布。
