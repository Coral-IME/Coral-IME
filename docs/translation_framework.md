# 阿里云翻译

## 使用

在设置 → 高级 → 翻译中开启功能，填写 AccessKey ID 与 AccessKey Secret，点击“保存凭据”。目标语言默认英语，原文固定按中文发送。客户端直接调用阿里云机器翻译通用版，不添加服务开通、登录或账户管理流程；服务拒绝请求时只显示错误提示。

AccessKey ID 输入框旁的“开通教程”为蓝色下划线文字链接，无按钮边框或填充背景；在翻译关闭时也可点击，由系统默认浏览器打开 https://coralime.cn/translation-help.html，不附带输入内容、设置或凭据。教程源码位于独立 website 仓库的 translation-help.html 与 assets/css/translation-help.css，沿用官网样式；官网导航、技术专栏和其他页面不添加入口，并设置 noindex/nofollow。页面说明阿里云服务开通、RAM 专用密钥与授权、计费和程序配置；服务开通仍由用户在阿里云完成。官网源码需随官网部署到该路径后，正式地址才可访问。

输入拼音或双拼后，在候选窗按无修饰键的翻译快捷键（默认 `=`，可在高级页选择 `F1`–`F12`）翻译已选中文前缀及当前高亮候选。后台请求期间显示“翻译中”，原输入保留；方向键选择译文，回车原样上屏。Esc 或退格取消翻译并恢复原候选与选择。未返回译文、失败或缺少凭据时，回车不提交提示或原文。译文不参与拼音词频学习、全角转换或候选规则编辑。U/UU/V 和剪贴板模式不打开翻译；Shift+= 仍输入 +。PageUp/PageDown 继续控制翻页。

按键页恢复 `- / +` 候选翻页，默认关闭，实际使用无修饰键的 `-` / `=` 两个键，方向分别为上一页 / 下一页。先开启该翻页再开启 `=` 翻译时，会提示冲突并保持翻译关闭，可先在关闭状态选择 F1–F12 再启用。先开启 `=` 翻译再开启翻页时，保留翻译设置但提示该快捷键失效，运行时翻页优先；改选 F1–F12 或关闭加减翻页后恢复翻译快捷键。翻译已开且加减翻页已开时，尝试选回 `=` 会提示冲突并保留上次选择。快捷键选项仅限 `=` 与 F1–F12，非法保存值回退 `=`，冲突检查同样生效。设置通过 INI 及共享设置同步到 TSF 快照，不改变核心或渲染协议。

目标语言提供 15 种：英语、印地语、西班牙语、法语、阿拉伯语、孟加拉语、葡萄牙语、俄语、乌尔都语、印度尼西亚语、德语、日语、马拉地语、泰卢固语、泰米尔语。此产品列表面向中文输入，排除中文目标、合并阿拉伯语分支；属于主要非中文语言选择，不做实时人数排名。语言代码来自[阿里云语言列表](https://help.aliyun.com/zh/machine-translation/support/supported-languages-and-codes)，共享定义位于 include/coral/translation/languages.h。非法持久化代码回退英语。

## 请求与生命周期

modules/translation 定义 coral::translation target，Windows 实现在 platform/windows/translation，使用 HTTPS POST https://mt.aliyuncs.com/，动作 TranslateGeneral、版本 2018-10-12、Scene=general、FormatType=text、SourceLanguage=zh；目标语言与候选原文以 UTF-8 表单发送。ACS3-HMAC-SHA256 由 Windows BCrypt 计算，复用项目内 libcurl 的 Schannel TLS 运输。详情参见[接口说明](https://help.aliyun.com/zh/machine-translation/developer-reference/api-alimt-2018-10-12-translategeneral)及[签名协议](https://help.aliyun.com/zh/sdk/product-overview/v3-request-structure-and-signature)。

网络运行在候选控制器拥有的后台加载线程，通过专用请求/结果队列与 owner-thread 消息交付。一次翻译只发送一次请求，不自动重试；连接预算 5 秒，总传输预算 15 秒，响应最多 1 MiB。curl multi 循环每至多 100ms 检查取消，校验证书与主机名，禁止重定向。取消移除本次传输，但服务器已开始处理的请求仍可能完成。析构先取消并等待后台线程，再销毁通知窗口。现有普通候选查询仍可能占用该线程，沿用既有会话预算。

退出、复位、重新进入会更新请求标识并取消旧任务。停用翻译立即恢复输入；目标语言或凭据修订变化会取消旧任务并对保留原文重新请求。旧结果按请求标识拒绝，不会覆盖新候选。后台异常只返回固定失败类型，不输出异常内容。网络、超时、凭据、语言、服务拒绝和无效结果有固定提示，不展示服务器原始响应或请求签名。

## 凭据

两项字段均以密码掩码显示。保存时用当前 Windows 用户的 DPAPI 加密为一个 Base64 blob，存于本机 INI 的 translationCredentials；不另建密码系统、不上传凭据到自有服务器。普通代码只在构造阿里云签名时使用凭据。配置快照与共享设置只有 translationKeyConfigured、translationCredentialRevision 和目标语言，不包含明文凭据或密文 blob，核心/渲染协议不传递凭据。

保存先成功写入 INI，再发布配置修订；失败显示保存失败。两项同时清空可删除凭据，关闭翻译保留凭据。旧单项 translationApiKey 不作为 AccessKey 使用，保存新凭据时删除旧项。后台从独立 INI reader 解密，避免与设置线程共用可变解析器。凭据不写入产品日志、测试源码、请求错误文本或候选内容；测试凭据也不作为默认值交付。DPAPI 解密失败显示需重新填写，不回退明文。
