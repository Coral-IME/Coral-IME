# TSF 编辑完成、光标与焦点边界

本次针对 Windows 文本服务的编辑完成语义，不改变候选生成策略。代码以 `2c682f4` 为基线的修改后工作树验证，包含前一项配置快照修改；未修改已安装输入法。

## 完成语义

`RequestEditSession` 的返回值和编辑会话的执行结果分开处理。`TF_S_ASYNC` 只表示排队，不能据此清空输入、更新输入历史或学习候选。请求失败、同步拒绝、实际执行及宿主释放未执行请求都只完成一次。

最终提交回报三个事实：`status`、`text_written`、`composition_ended`。

| 边界 | 行为 |
|---|---|
| 写入前失败 | 保留本地输入与选词，可再次提交；不学习、不记录成功历史。 |
| `SetText` 成功 | 立即标记已写入，随后定位、结束组串失败也不能重放文字。 |
| 定位失败 | 仍尝试结束同一组串；按实际写入结果消费输入。 |
| 结束组串失败 | 保护已写入范围，禁止预编辑覆盖和取消清空；后续输入只重试结束旧组串。 |
| 本服务主动结束组串 | `OnCompositionTerminated` 不抢先清空本地输入，由提交完成回调消费对应前缀。 |
| 宿主主动终止组串 | 使旧编辑请求失效，按原流程清理该上下文。 |

同一组串只接受一个待完成的最终提交，防止重复选词造成二次写入。等待期间追加的拼音可以保留：提交前复核已选前缀没有被改写；完成时只消费该前缀，剩余输入重新建立组串。关闭、取消、失焦后重新组字，即使文本相同，也不会复用旧请求。

候选的学习、预测上下文和输入历史随实际成功写入确认。写入期间焦点已变化时，不通过全局活动控制器修改另一个输入框的历史或候选界面。

## 光标与焦点

- 光标定位先克隆组串范围，在临时范围上移动；以组串末尾作为停止边界，核对请求距离与实际移动距离相等，最后才设置宿主选区。负数、克隆失败、部分移动、折叠失败均不改变选区。
- 几何查询初始化选区和矩形，核对返回数量与范围，并用 RAII 释放选区。失败时不发布未初始化坐标；系统插入符回退成功才使用回退结果。
- 写入、预编辑、占位符和光标请求携带编辑代次与焦点代次；执行前及可重入的宿主调用之后重新核对。
- 焦点校验核对实际线程焦点、文档管理器和顶部上下文的 COM 身份。焦点查询失败时拒绝写入。
- 线程失焦、上下文切换、关闭与停用使排队请求失效。关闭时先失效旧请求，再尝试同步清理已有组串，最后退役控制器。旧完成回调不能清除新请求的等待标记。

日志 `event=commit_completed` 记录操作编号、HRESULT、`text_written` 与 `composition_ended`，不记录输入内容。可据此区分“未写入”与“写入后收尾失败”。

## 自动验证

`tsf_edit_boundaries_test` 用人工构造的 COM 宿主替身运行生产 `editsession.cpp`，覆盖同步/异步完成、请求拒绝、未执行即释放、重复回调、写入失败、选区失败、结束失败、取消不删除已写文字、焦点往返、关闭、组串替换、宿主重入、旧完成不影响新请求、待开始组串取消、部分光标移动和几何查询失败。

`translation_controller_test` 增加实际写入前不学习、失败后再次选词不重复拼接、完成只学习一次、追加输入保留和相同文本的新组串拒绝旧回调检查。既有预测测试改为显式确认写入完成。

这些测试不注册 TSF、不操作真实编辑器和安装用户数据，不能代替实际宿主验收。

## 人工复现清单

使用测试安装，在记事本、Word/WPS、浏览器普通输入框与富文本框、至少一个 32 位应用中分别验证：

1. 输入 `nihao`，依次用空格、数字、鼠标选词和回车提交；继续输入第二词。检查只上屏一次、候选关闭时机正常，第二词没有被旧回调清空。
2. 在两个输入框之间切换、Alt+Tab 切换进程；分别在输入拼音期间及按下选词键后立即切换，再返回输入。检查没有跨框上屏或跨框移动光标。
3. 输入期间关闭窗口、标签页、弹窗，或切换输入法后立即重新启用；检查没有迟到候选、旧文字插入或崩溃。
4. 组词后使用左右、Home、End 定位，在中文选词前缀与剩余拼音之间移动并输入、删除；检查候选分段与宿主插入符一致。
5. 分别启用全角、自动配对符号，输入配对符号并在按键期间切换焦点；检查只有文字确实写入且焦点仍有效时才执行补全后的左移。
6. 快速连续输入 `nihao`、空格、`shijie`、空格，以及选词后紧接标点，检查延迟写锁宿主中输入顺序和最终文字。若发生异常，保存 `commit_completed` 前后同一操作编号的日志。

真实应用通常无法稳定制造“SetText 成功但 EndComposition 失败”等细分故障，此类失败由自动宿主替身精确注入；不能仅凭某个应用一次输入正常推断这些边界已被实际触发。
