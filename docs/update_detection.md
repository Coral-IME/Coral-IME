# 第一版更新检测框架

2026-10-15：第一版只检测版本并提示用户打开 GitHub 发布页，自行下载安装。本文件描述当前生产入口；`update_private_channel.md` / `update_package_acceptance.md` 保留先前下载设施的历史契约，不表示第一版会使用这些设施。

## 客户端行为

- 关于页保留“检查更新”，新增默认开启的“自动检查更新”开关，复用 `isAutoCheck` 设置。
- 用户设置进程的 apphost 启动约 60 秒后开始调度，每分钟评估一次；距离上次已发起检查不足 24 小时不创建请求。`updateLastCheckUtc` 为本机 INI 的 UTC 秒数字符串，手动检查也更新时间但不受间隔限制；失败也计入间隔，避免重启和断网重试风暴。损坏值视为首次检查，时钟回拨允许重新检查一次。
- 手动点击会将正在进行的自动检查提升为手动结果；后台定时器不覆盖手动模式，不并发发起请求。
- 四段版本按数值逐段比较，不按字符串字典序。相同版本或较旧版本不提醒；手动显示“当前已是最新版本”。比较来源为运行程序的版本资源，不信任服务端返回的本地版本。
- 新版窗口展示只读、可滚动的更新说明和“前往下载 / 稍后”。自动显示不主动抢焦点。点击下载仅以 ShellExecute 打开校验过的 HTTPS GitHub 固定版本发布页；失败在窗口内提示。没有创建下载子进程、写安装包缓存或启动安装程序的客户端通路。
- `updateLastNotifiedVersion` 为本机 INI；同一版本已展示后不再自动弹窗，手动检查仍可展示。关闭开关也抑制正在进行的自动检查结果；手动检查继续可用。
- 主程序退出前显式停止协调器，使 weak lifetime token 失效，取消并等待检查线程，随后销毁窗口；迟到的主线程任务不再访问协调器。

## 接口及配置

复用 `CORAL_UPDATE_SERVICE_BASE_URL`，默认为空；没有公网占位地址和旧主机回退。配置后只请求 `<base>/api/v1/version/latest`。第一版接口采用独立的 `UpdateNotice` 契约，与旧下载必需的 id/大小/SHA256 元数据分离：

```json
{
  "schema_version": 1,
  "data": {
    "version": "1.0.0.4",
    "description": "更新说明",
    "release_url": "https://github.com/OWNER/REPO/releases/tag/v1.0.0.4"
  }
}
```

输入必须为有效 UTF-8，最多 64KiB；根对象及 data 对象拒绝重复键，协议版本必须为整数 1。四段版本各为 0..65535 且不带多余前导零，说明最多 16384 UTF-8 字节。发布页地址最多 2048 字节，固定 `https://github.com/owner/repo/releases/tag/tag`，各段仅允许 ASCII 字母、数字、点、横线和下划线，拒绝单独的点/双点、凭据、端口、查询参数、片段及其他域名。解析失败保留先前输出，不展示部分解析结果。

沿用已有 HTTPS 请求的证书校验、不跟随重定向、5 秒连接/30 秒请求预算、取消和接收上限。自动检查失败保持安静；手动区分未配置、网络失败、无效信息、本地版本读取失败及没有新版。未配置服务时不发起请求，也不写检查时间。

服务端位于 `server-side/` 独立仓库（默认与客户端仓库同级，接入方式见 [构建说明](build.md#独立服务端仓库)）：Python 标准库实现只读版本服务，显式指定版本文件，逐请求重新校验，错误返回 503；示例文件不作为默认正式源。可部署到现有 HTTPS 反向代理之后。没有访问 GitHub、数据库、用户身份或认证密钥。

## 本地验收及后续边界

新增 C++ 人工夹具覆盖协议、URL、错误编码/重复键/超限、事务性输出、四段版本及每日调度；直接解析服务端同一示例。服务端使用临时文件/本机临时端口验证 GET/HEAD、热更新、失败、未知路由与拒绝 POST。设置窗口测试检查自动开关默认值、四档 DPI 布局，并使用隐藏的真实新版窗口验证说明换行、发布页动作及关闭，不实际打开浏览器。

本次不连接 GitHub 或公网更新服务器，不部署、不安装、不替换现用程序。正式发布前需确定实际 HTTPS 更新基础地址、GitHub 仓库及版本标签，配置正式构建并验证 DNS/TLS/接口响应、浏览器跳转及安装包下载。旧下载设施仍保留供未来单独开发，不计为本版支持自动更新。
