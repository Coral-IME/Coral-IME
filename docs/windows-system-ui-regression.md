# Windows 宿主窗口人工回归

本页是当前候选的人工验证清单，不能视为已安装版本的通过记录。整理过程中没有替换本机已安装程序或重新注册 TSF。

当前实现为 Taskmgr.exe 等特殊宿主保留进程内候选窗路径，并通过前台应用、上下文令牌及快照版本检查过滤渲染动作。自动测试覆盖协议、窗口状态和 TSF 状态内核；真实 Windows 宿主交互仍需安装后另行验证。

## 验证场景

1. 桌面无编辑上下文时，悬浮栏不重复残留，菜单状态正确。
2. 记事本输入后切回桌面，焦点、菜单和状态切换可用。
3. 任务管理器搜索框中的候选窗保持在宿主上方，能选择、展开和滚动。
4. 普通窗口与管理员窗口切换后，仅前台应用对应的候选和悬浮栏显示。
5. 桌面搜索、UWP 编辑框、大 DPI 与多显示器下位置和交互正确。
6. 全屏窗口及切换输入法时隐藏行为正确，旧快照点击不会作用于新上下文。

相关自动检查为 renderer_window_state、renderer_protocol_v3、tsf_state、tsf_sink_contract。构建方法见 [构建](build.md)，产物位于 `build/<预设>/coralpinyin/<配置>/`；不得从作者机器上的旧路径获取测试程序。

候选布局与提交约束见 [候选窗维护说明](windows-candidate-window.md)。记录实际宿主、权限、DPI、构建版本和通过/失败场景；不要将旧开发阶段结果作为新安装包的验收依据。
