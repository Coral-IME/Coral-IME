# 公共资源

`config/` 保存主配置模板和双拼 INI 方案；`icons/` 保存安装器使用的图标。真实用户自定义内容及服务凭据未带入模板。

项目维护者已确认自定义 UI 辅助代码、项目图标与候选窗皮肤为自有或有权按项目许可开源的作品。项目自有资源适用 MPL-2.0；原有署名保留，商标权不由 MPL 授予。详见 [许可范围](../LICENSING.md)。

正式词库和模型在候选之外；自制演示输入在 `samples/demo/fixtures/`，输出位于构建目录。公共配置已接入 CMake。使用方式见 [数据边界](../docs/data-boundary.md) 和 [数据工具](../docs/data-tools.md)。
